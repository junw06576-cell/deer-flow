# Excel 生成规范

## Sheet 结构

每个产品 1 个 sheet + 1 个项目汇总 sheet。

## 17 列定义（A-Q）

| 列 | 字段 | 说明 |
|---|---|---|
| A | 部署类型 | 正式/生产/测试环境，连续相同值合并 |
| B | 产品 | 产品名，连续相同值合并 |
| C | 服务明细 | 服务描述 |
| D | 选项 | 必选/可选 |
| E | 资源类型 | 应用服务器/数据库服务器 |
| F | 服务器数量 | int, 格式 #,##0 |
| G | CPU（核） | int, 格式 #,##0，每台服务器的CPU核数 |
| H | 内存（GB） | int, 格式 #,##0 |
| I | 系统盘（GB） | int, 格式 #,##0，通常100 |
| J | 数据盘（GB） | int, 格式 #,##0 |
| K | 磁盘要求 | 高性能/SSD |
| L | 操作系统版本 | |
| M | 应用中间件 | |
| N | 数据库 | |
| O | 开放端口 | |
| P | 建议带宽 | |
| Q | 备注 | |

## 行布局

```
Row 1: 标题行（merged A1:Q1，如"眉县医共体 - WXP运维平台（必选）"）
Row 2: 副标题行（merged A2:Q2，如"WXP为所有项目必选公共组件"或档位信息）
Row 3: 表头行（17列，加粗，浅蓝填充 #D9E2F3）
Row 4~N: 数据行
Row N+1: 合计行
```

副标题格式：
- WXP: "WXP为所有项目必选公共组件"
- 基层医疗: "档位：第X档（条件描述）"
- 公卫类: "档位：第X档（条件描述）| 区域人口：XXX万"
- 区域平台: "档位：第X档（条件描述）| 区域人口：XXX万"

## 合计行公式

```
F(合计) = =SUM(F{ds}:F{de})
G(合计) = =SUMPRODUCT((F{ds}:F{de})*(G{ds}:G{de}))
H(合计) = =SUMPRODUCT((F{ds}:F{de})*(H{ds}:H{de}))
I(合计) = =SUMPRODUCT((F{ds}:F{de})*(I{ds}:I{de}))
J(合计) = =SUMPRODUCT((F{ds}:F{de})*(J{ds}:J{de}))
```

合计行样式：加粗，浅蓝填充 #D9E2F3，A列合并A:E写"合计"。

## 合并单元格规则

- **部署类型（A列）**：连续相同的部署类型值合并
- **产品（B列）**：连续相同的产品名合并
- 注意：硬件负载行参与部署类型和产品的合并，但不影响数值计算

## 特殊行处理

### 硬件负载行（基层医疗 tier 2-4）

- 只填：C=服务明细, D=可选, E=应用服务器
- F/G/H/I/J 全部为 None/空
- 不影响 SUMPRODUCT（F为空自动跳过）

### WXP（固定配置）

| 服务明细 | 选项 | 资源类型 | 数量 | CPU | 内存 | 系统盘 | 数据盘 | 磁盘要求 | OS |
|---|---|---|---|---|---|---|---|---|---|
| 自动化运维工具前置机 | 必选 | 应用服务器 | 1 | 4 | 8 | 100 | 50 | 高性能 | Kylin Linux Advanced Server V10 只支持欧拉SP3或者麒麟操作系统 |
| 自动化运维工具 | 必选 | 应用服务器 | 1 | 8 | 32 | 100 | 500 | 高性能 | 同上 |

## 项目汇总 Sheet

### 项目信息区

| 行 | 内容 |
|---|---|
| 1 | 标题（merged A1:F1）|
| 3~N | 项目信息键值对（A列=key加粗, B列=value）|

必须包含：项目名称、建设范围、常住人口、信创环境、各产品档位

### 汇总表

标题行："各产品服务器资源汇总（数量×配置）"

表头：产品 | 服务器数量 | CPU（核） | 内存（GB） | 系统盘（GB） | 数据盘（GB）

跨 sheet 引用（关键映射）：
```
B列(服务器数量) → 产品sheet!F{合计行}
C列(CPU)       → 产品sheet!G{合计行}
D列(内存)       → 产品sheet!H{合计行}
E列(系统盘)     → 产品sheet!I{合计行}
F列(数据盘)     → 产品sheet!J{合计行}
```

合计行：`=SUM(B{首}:{末})` ... `=SUM(F{首}:{末})`

## 数值格式

- 所有数值存为 Python int/float，不存为字符串
- F-J 列使用 `#,##0` 数字格式
- 跨 sheet 引用单元格也用 `#,##0` 格式

## 样式规范

复用已有项目 Excel 文件作为样式模板，读取并复制：
- 标题行字体/对齐
- 表头行字体/填充/对齐
- 数据行字体/边框
- 列宽
- 合计行字体/填充

不要在 sheet 底部添加"数据来源"等脚注。
