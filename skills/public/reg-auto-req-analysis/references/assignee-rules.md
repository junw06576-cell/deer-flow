# 指派人速查清单（AUTO-ANA 自动指派）

> **本文件是 skill 自备的精简清单**，蓝本为仓库根 `05_指派人规则.md`（人写权威源）。运行时**不引用根文件**；新增产品/指派**直接在本文件加节**。
>
> 仅用于 `AUTO-ANA`：按「产品 × 版本 ×（模块）」匹配**唯一**开发组长，写入 `System.AssignedTo`（计划字段 `assignee_to`）。
> **匹配不出**（范围外产品 / 混合版本且模块不清 / 命中多人）→ **不写指派**，在分析者描述与审计里写明候选与原因，`AUTO-ANA` 仍正常流转到「已分析」（指派与终局置信度解耦）。
>
> 本清单**不含**特殊情况（跨组/BUG/紧急/不在岗/新功能/复杂调整）、决策流程图、组名别名、数据验证叙述——这些留在根 `05_` 供人参考，不进自动判定。

## 一、版本判定（从 `Winning.Prod.Version` 字段，**不从迭代路径**）

迭代路径统一为 `NETHIS5.5\...`，无区分度。版本号取 TFS `Winning.Prod.Version` 字段：

- 同时含 `5.5` 和 `5.6` → **混合**（需按模块细分，见 §三）
- 只含 `5.5` → **5.5**
- 其它（含 `5.6`，或 `V6.0.*`、`0509`、`20260410` 等迭代格式，或为空）→ **5.6**（当前主推版本）
